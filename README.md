# 🛡️ Mutekano App

## 📌 Overview
**Mutekano App** is a smart web-based surveillance system designed to provide **real-time monitoring and security** for homes and farms. It connects ESP32-CAM devices to a centralized backend, allowing users to monitor their property remotely through a modern web application.

👉 *“Igenzura ry’urugo rwawe mu gihe nyacyo”* (Live monitoring of your home)

---

## 🎯 Features
- 📡 Real-time home monitoring  
- 📸 Image capture and storage  
- 🚨 Motion detection alerts  
- 🌐 Remote access via web application  
- 🖥️ Device management dashboard  
- 🔒 Secure authentication system  
- 📶 Optimized for low-bandwidth environments
